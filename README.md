# zikr-athkar-data

Athkar and duaa content for the Zikr app, published as downloadable packs.

## Layout

- `zikr_athkar_manifest.json` — the manifest the app reads. It lists every
  pack with its group, kind, item count, size, sha256 and download URL.
- Releases (`v<data version>`) carry the assets:
  - `zikr_athkar_<pack>.zip` — one per category: `zikr_athkar_<pack>.json`
    plus `audio/<key>.m4a` recitations where the pack has them.
  - `zikr_athkar.sqlite` — the normalized master database every pack is
    built from.

## Pack format

`zikr_athkar_<pack>.json`:

```json
{
  "schemaVersion": 1,
  "dataVersion": "2026.09.1",
  "key": "morning",
  "kind": "reader",
  "items": [
    {
      "id": 25,
      "title": "…",
      "segments": [{"k": "quran", "t": "…"}, {"k": "note", "t": "…"}],
      "count": 3,
      "audio": "audio/morning_002.m4a",
      "textEn": "…",
      "translit": "…"
    }
  ]
}
```

Segment kinds: `heading`, `text`, `quran`, `note`, `repeat`. Text may carry
`**bold**` spans. `{p}` and `{h}` in family and sick duaa are filled in by
the app with a name and a pronoun suffix.

Packs are generated by the app repository's `tool/athkar/build_release.py`;
do not edit release assets by hand.
